# trabalho_final_BD

Sistema de Acompanhamento do Ciclo Menstrual

O projeto consiste no desenvolvimento de um banco de dados para um sistema de acompanhamento menstrual. O sistema tem como objetivo permitir o registro e a organização de informações relacionadas aos ciclos menstruais, possibilitando o acompanhamento do histórico de cada usuária.

A aplicação permitirá registrar ciclos, fluxo menstrual, sintomas, humores, medicamentos utilizados e fases do ciclo, mantendo essas informações organizadas para consultas posteriores.

O sistema será desenvolvido para auxiliar no registro e acompanhamento de informações relacionadas ao ciclo menstrual, permitindo consultar o histórico dos ciclos, sintomas, humores, fluxo e demais informações registradas.
